# * What we need to remember

1. Python is a versatile **programming language** that is widely used for various applications including web development, data analysis, artificial intelligence, scientific computing, and more.

2. Programming in Python is fast, but it can have a **slower execution speed** compared to languages like C or C++ due to its interpreted nature. This can be mitigated to some extent by using optimized libraries or implementing performance-critical parts in other languages.

3. Python can be used in a ".py" file and in a ".ipynb" file (Jupyter Notebook). Jupyter Notebook is used for interactive computing, data exploration, and visualization, making it popular for data science and research purposes. py files are used for writing scripts and modules that can run as an independent script or program.

4. You need to remember all the material from the **Python Basics** text and from the **Global Variables** text. You can use the bot to help you do that.

5. Python can write and read from text files, and the code is fairly simple. We use the **with** statement to ensure that files are properly closed after we are done with them. The **with** statement is also used for other resources we didn't learn about yet.

6. We can read the entire text file into a string, or we can use a loop and read it line by line.

7. there are several types of text file formats, one of which is the **CSV file (.csv)**.
   - **Plain text files (.txt)**: Contain unformatted text and are the simplest type of text file.
   - **CSV files (.csv)**: Comma-separated values files used for tabular data.

   if we create a .csv file and ask the operating system to open it, it will typically open it in excel and place the data into separate cells based on the commas.
