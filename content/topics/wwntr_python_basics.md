# * What we need to remember

1. Python is a versatile **programming language** that is widely used for various applications including web development, data analysis, artificial intelligence, scientific computing, and more.

2. Programming in Python is fast, but it can have a **slower execution speed** compared to languages like C or C++ due to its interpreted nature. This can be mitigated to some extent by using optimized libraries or implementing performance-critical parts in other languages.

3. You need to remember all the material from the **Python Basics** text and from the **Global Variables** text. You can use the bot to help you do that.

4. Python can be used in a ".py" file and in a ".ipynb" file (Jupyter Notebook). Jupyter Notebook is used for interactive computing, data exploration, and visualization, making it popular for data science and research purposes. py files are used for writing scripts and modules that can run as an independent script or program.
