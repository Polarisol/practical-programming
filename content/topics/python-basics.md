# Python basics

## Variables

A variable is a name that stores a value:

```python
name = "Dana"
age = 15
print(f"{name} is {age} years old")
```

## Loops

Use `for` to repeat something:

```python
for i in range(3):
    print("Hello", i)
```

## Functions

A function is a reusable block of code:

```python
def square(n):
    return n * n

print(square(4))  # 16
```
