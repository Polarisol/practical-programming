# * What we need to remember

1. Numpy can deal with data much faster and more efficiently than regular Python lists. Backstage it is written in C, which is why it is so fast.

2. Numpy allows us to create 1D arrays, as well as multi-dimensional arrays, which are useful for representing matrices and higher-dimensional data. see **Creating Arrays** in the **NumPy Basics** section.

3. NumPy supports element-wise operations on arrays, which means we can perform mathematical operations on entire arrays without writing loops. the loops are handled internally in C, making the operations much faster. see **Array Operations** in the **NumPy Basics** section.

4. NumPy provides a wide range of functions for creating, manipulating, and performing computations on arrays efficiently. don't use the Math module for array operations - use NumPy's functions instead. see **Array Operations** in the **NumPy Basics** section.

5. We need to remember how to turn a list into a NumPy array using `np.array()`, how to work with `linspace` and `arange` to create arrays. see **Creating Arrays** in the **NumPy Basics** section.

6. We need to remember the ways to get a random number, or numbers, using the methods of `np.random`: `np.random.rand()`, `np.random.randint()`, and `np.random.uniform()`, and what each method does. see **Random Numbers** section.

7. Random numbers generated by a computer are **pseudo-random**, meaning they are determined by an initial value called a seed. If we use the same seed, we will get the same sequence of random numbers. **They are not truly random.**

8. Numpy include linear algebra functions and operations. You do not need to remember them by heart; just know that they exist and can be used when needed.

9. Numpy provides functions for polynomial fitting and evaluation. You do not need to remember them by heart; just know that they exist and can be used when needed.
