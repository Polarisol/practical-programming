# * What we need to remember (basic)

1. PySide6 is a robust, trusted framework for creating GUI applications in Python. It uses the Qt library for its underlying implementation, and products built with it can be found everywhere.

2. You have to understand the basics of PySide6: what is the event loop (`app.exec()`), how to create and manage widgets like `button = QPushButton("Click me", window)`, and how signals and slots work (using `connect`). You should also be able to read and understand such code when you see it.

3. You don't have to remember every single widget and its properties. But you should recognize the most commonly used ones when you see them and know what they are used for. So if you see a `DoubleSpinBox` in the code you know what it is there for and what are its limitations. See the "Widget Reference" item.

4. You should know what `setGeometry` and how to use it.

5. You should know what `setStyleSheet` does. AI will do a great job of writing the initial styles for you, but you should be comfortable with modifying them to suit your needs.

6. You should be able to look at a simple short program using PySide6, follow the logic, and understand what it does.
