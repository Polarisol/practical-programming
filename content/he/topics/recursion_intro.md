# מבוא

**רקורסיה** (recursion) היא כשפונקציה קוראת **לעצמה**. במקום לפתור את כל הבעיה בבת אחת, הפונקציה פותרת חתיכה קטנה ומעבירה את השאר לעותק קטן יותר של אותה בעיה.

לכל פונקציה רקורסיבית יש שני חלקים:

1. **מקרה בסיס** (base case) - מקרה כל כך פשוט שהפונקציה עונה עליו ישירות, בלי לקרוא לעצמה. כאן הרקורסיה נעצרת.
2. **צעד רקורסיבי** (recursive step) - הפונקציה קוראת לעצמה על גרסה **קטנה יותר** של הבעיה, ומשתמשת בתשובה הזו כדי לבנות את התשובה שלה.

כל קריאה חייבת להתקרב למקרה הבסיס. אחרת הפונקציה תקרא לעצמה לנצח.

## דוגמה פשוטה: כפל

כפל הוא חיבור חוזר. `a * b` זה `a` שמחובר לעצמו `b` פעמים. אפשר לנסח את זה באופן רקורסיבי:

- `a * 0` הוא `0` (מקרה בסיס)
- `a * b` הוא `a + a * (b - 1)` (צעד רקורסיבי)

```python
def multiply(a, b):
    if b == 0:                         # base case
        return 0
    return a + multiply(a, b - 1)      # recursive step

print(multiply(4, 3))  # 12
```

הנה מה שקורה כשקוראים ל-`multiply(4, 3)`:

```
multiply(4, 3) = 4 + multiply(4, 2)
               = 4 + (4 + multiply(4, 1))
               = 4 + (4 + (4 + multiply(4, 0)))
               = 4 + (4 + (4 + 0))
               = 12
```

כל קריאה מחכה שהקריאה שמתחתיה תסתיים. כשמקרה הבסיס מחזיר `0`, התשובות עולות בחזרה למעלה ומתחברות יחד.

## מגדלי הנוי

מגדלי הנוי (Towers of Hanoi) הם חידה עם שלושה מוטות וערימה של דיסקיות בגדלים שונים. בהתחלה, כל הדיסקיות יושבות על המוט הראשון, מהגדולה ביותר למטה ועד הקטנה ביותר למעלה.

![מגדלי הנוי: ארבע דיסקיות מוערמות על מוט A, והמוטות B ו-C ריקים](content/images/towers_of_hanoi.svg)

המטרה היא להעביר את כל הערימה למוט האחרון. החוקים הם:

1. מזיזים **דיסקית אחת בכל פעם**.
2. אפשר לקחת רק את הדיסקית ה**עליונה** של מוט.
3. **אסור** אף פעם להניח דיסקית על דיסקית קטנה ממנה.

לפתור את זה ביד זה קשה ברגע שיש יותר מכמה דיסקיות. עם רקורסיה זה קצר. כדי להעביר `n` דיסקיות ממוט A למוט C:

1. מעבירים את `n - 1` הדיסקיות העליונות מ-A ל-B (בעזרת C כמוט עזר).
2. מעבירים את הדיסקית הגדולה ביותר מ-A ל-C.
3. מעבירים את `n - 1` הדיסקיות מ-B ל-C (בעזרת A כמוט עזר).

שלבים 1 ו-3 הם אותה חידה עם דיסקית אחת פחות, ולכן הפונקציה יכולה לקרוא לעצמה בשבילם. מקרה הבסיס הוא דיסקית בודדת, שפשוט מזיזים.

```python
def hanoi(n, start, target, helper):
    if n == 1:                                 # base case
        print(f"Move disk 1 from {start} to {target}")
        return
    hanoi(n - 1, start, helper, target)        # move n-1 disks out of the way
    print(f"Move disk {n} from {start} to {target}")
    hanoi(n - 1, helper, target, start)        # put them back on top

hanoi(3, "A", "C", "B")
```

פלט:

```
Move disk 1 from A to C
Move disk 2 from A to B
Move disk 1 from C to B
Move disk 3 from A to C
Move disk 1 from B to A
Move disk 2 from B to C
Move disk 1 from A to C
```

העברה של `n` דיסקיות דורשת `2**n - 1` מהלכים. 3 דיסקיות דורשות 7 מהלכים, אבל 64 דיסקיות ידרשו יותר מ-18 קווינטיליון מהלכים.
