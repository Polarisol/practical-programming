# למה SymPy?

## למה SymPy חשובה ב-Python

Python מצוינת בחישובים עם מספרים. ספריות כמו NumPy יכולות לבצע מיליוני חישובים בשנייה. אבל מספרים הם רק חצי מהסיפור. לפני שאפשר לחשב, לעיתים קרובות צריך את **הנוסחה**: מה הנגזרת של הפונקציה הזו? איזה `x` פותר את המשוואה הזו? מה ההופכית של המטריצה הזו?

על הנייר מוצאים את הנוסחה בעזרת אלגברה, וזה איטי וקל לטעות בזה. **SymPy** נותנת ל-Python לעשות את האלגברה בשבילכם:

- **תשובות מדויקות.** `sqrt(2)` נשאר `√2` ו-`1/3` נשאר `1/3`. אין שגיאות עיגול שמתחבאות בתוצאה.
- **נוסחאות, לא רק מספרים.** מקבלים תשובה כללית עם אותיות, ואפשר להשתמש בה שוב לכל ערכים שתרצו אחר כך.
- **בדיקת העבודה שלכם.** אפשר לבדוק את שיעורי הבית, או את הנוסחה שהעתקתם מספר, בשורה אחת.
- **Python טהור.** היא חינמית, מותקנת בפקודה אחת, ועובדת יחד עם NumPy ו-Matplotlib.

בגלל זה משתמשים ב-SymPy בבתי ספר, באוניברסיטאות, במעבדות מחקר ובחברות הנדסה. היא "מחברת המתמטיקה" של עולם ה-Python.

## איך משתמשים ב-SymPy ברובוטיקה

רובוט מלא במתמטיקה: זוויות, מרחקים, מהירויות, כוחות. מהנדסים משתמשים ב-SymPy כדי **למצוא** את המשוואות פעם אחת, ואז התוכנית של הרובוט משתמשת במשוואות האלה כדי **לחשב** מהר, הרבה פעמים בשנייה.

### איפה היד של זרוע הרובוט? (קינמטיקה)

חשבו על זרוע רובוטית פשוטה עם שני חלקים (חוליות) באורכים `L1` ו-`L2`, ושני מנועים שמסתובבים בזוויות `θ1` ו-`θ2`. איפה נמצאת היד (קצה הזרוע)? עם קצת טריגונומטריה:

```python
import sympy as sp

t1, t2, L1, L2 = sp.symbols('theta1 theta2 L1 L2')

x = L1*sp.cos(t1) + L2*sp.cos(t1 + t2)
y = L1*sp.sin(t1) + L2*sp.sin(t1 + t2)
```

```math
x = L_{1} \cos{\left(\theta_{1} \right)} + L_{2} \cos{\left(\theta_{1} + \theta_{2} \right)}
y = L_{1} \sin{\left(\theta_{1} \right)} + L_{2} \sin{\left(\theta_{1} + \theta_{2} \right)}
```

זה נקרא **קינמטיקה ישירה** (forward kinematics): מזוויות המנועים אל המיקום של היד. השאלה ההפוכה, "אילו זוויות ישימו את היד בנקודה שאני בוחר?", נקראת **קינמטיקה הפוכה** (inverse kinematics), והיא דורשת לפתור משוואות, וזה בדיוק מה ש-`sp.solve` עושה.

### כמה מהר היד זזה? (היעקוביאן)

כשהמנועים מסתובבים קצת, כמה היד זזה? התשובה היא מטריצה של נגזרות שנקראת **היעקוביאן** (Jacobian). ביד זו הרבה עבודה; SymPy עושה את זה בשורה אחת:

```python
J = sp.Matrix([x, y]).jacobian([t1, t2])
print(sp.simplify(J.det()))
```

```math
\det J = L_{1} L_{2} \sin{\left(\theta_{2} \right)}
```

התוצאה מספרת לנו משהו חשוב: כש-`sin(θ2) = 0` (הזרוע מתוחה עד הסוף או מקופלת עד הסוף) הדטרמיננטה היא 0. במצב הזה, שנקרא **סינגולריות** (singularity), הזרוע לא יכולה להזיז את היד שלה לכל כיוון. מתכנתי רובוטים חייבים להימנע ממנו, ו-SymPy מצאה אותו בשבילנו.

### עוד דוגמאות

- **תכנון תנועה.** מציאת מסלול חלק למנוע, למשל פולינום שמתחיל ונעצר במהירות 0, בעזרת פתרון מערכת משוואות.
- **דינמיקה.** קבלת משוואות התנועה של רובוט (כוחות, מומנטים, כבידה) מתוך הפיזיקה. ל-SymPy יש אפילו מודול מיוחד לזה, `sympy.physics.mechanics`.
- **בקרה.** תכנון ובדיקה של בקרים ששומרים על רובוט מאוזן או נע על קו, בעזרת נגזרות, התמרות לפלס ומשוואות דיפרנציאליות.
- **חיישנים.** סיבוב והזזה של קואורדינטות בעזרת מטריצות סיבוב, למשל מנקודת המבט של המצלמה לנקודת המבט של הרובוט.

### מנוסחה לקוד של רובוט

רובוט לא יכול לחכות ש-SymPy תעשה אלגברה בזמן שהוא בתנועה. לכן תהליך העבודה המקובל הוא:

1. **למצוא** את הנוסחה עם SymPy (פעם אחת, על המחשב שלכם).
2. **להפוך אותה לקוד מהיר** עם `sp.lambdify` (תראו אותו בסוף השיעור הבא), או להדפיס אותה כקוד עם `sp.pycode` או אפילו `sp.ccode` לתוכניות C על מיקרו-בקרים.
3. **להשתמש** בפונקציה המהירה הזו בתוכנית של הרובוט.
