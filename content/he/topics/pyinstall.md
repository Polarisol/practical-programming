# PyInstall

כשהתוכנית שלכם מוכנה, אולי תרצו לתת אותה למישהו שאין לו Python, uv או VS Code. **PyInstaller** אורז את התוכנית שלכם, את מפרש ה-Python ואת כל הספריות שהיא משתמשת בהן לתוך תיקייה או לקובץ `.exe` יחיד. האדם השני פשוט לוחץ עליו לחיצה כפולה, בלי להתקין כלום.

> PyInstaller בונה עבור המערכת שהוא רץ עליה. בנו ב-Windows כדי לקבל `.exe` של Windows, וב-Mac כדי לקבל אפליקציה של Mac. אי אפשר לבנות `.exe` של Windows על Mac (וגם לא להפך).

## 1. הוספת PyInstaller לפרויקט

פתחו את הפרויקט ב-VS Code, פתחו את הטרמינל וכתבו:

```bash
uv add --dev pyinstaller
```

`--dev` מסמן את PyInstaller ככלי שמשתמשים בו בזמן הפיתוח, ולא כספרייה שהתוכנית צריכה כדי לרוץ.

לפני הבנייה, ודאו שהתוכנית רצה כמו שצריך עם **Ctrl+F5**. PyInstaller אורז את התוכנית כמו שהיא, כולל הבאגים.

## 2. תיקייה אחת (ברירת המחדל)

כדי לבנות, הריצו `pyinstaller` עם שם הקובץ שמפעיל את התוכנית שלכם:

```bash
uv run pyinstaller main.py
```

`uv run` מריץ את הפקודה בתוך ה-`.venv` של הפרויקט, כך ש-PyInstaller רואה כל ספרייה שהוספתם עם `uv add`.

כשהוא מסיים, יש כמה דברים חדשים בתיקיית הפרויקט:

- `dist\main\`: **התוצאה.** תיקייה עם `main.exe` ולידו תיקייה בשם `_internal`, שמכילה את Python ואת הספריות.
- `build\`: קבצים זמניים ש-PyInstaller השתמש בהם תוך כדי עבודה. אפשר למחוק אותה.
- `main.spec`: קובץ עם ההגדרות של הבנייה. גם אותו אפשר למחוק.

כדי לתת את התוכנית למישהו, כווצו (zip) את כל התיקייה `dist\main` ושלחו אותה. הוא יחלץ אותה ויקליק פעמיים על `main.exe`. קובץ ה-`.exe` לא עובד בלי התיקייה `_internal` שלידו, אז תמיד שלחו את כל התיקייה.

> טיפ: הוסיפו את `build/`, `dist/` ו-`*.spec` לקובץ `.gitignore` של הפרויקט, כדי שתוצרי הבנייה לא יגיעו ל-git.

## 3. קובץ אחד

כדי לקבל הכול בקובץ `.exe` יחיד, הוסיפו `--onefile`:

```bash
uv run pyinstaller --onefile main.py
```

עכשיו ב-`dist\` יש רק קובץ אחד, `main.exe`, שקל לשלוח.

ההבדל בין השניים:

| | תיקייה אחת (ברירת מחדל) | קובץ אחד (`--onefile`) |
|---|---|---|
| מה שולחים | תיקייה שלמה (מכווצת) | `.exe` יחיד |
| הפעלת התוכנית | מהירה | איטית יותר: בכל הרצה היא קודם מחלצת את עצמה לתיקייה זמנית |
| אנטי-וירוס | בדרך כלל בסדר | מסומנת בטעות כחשודה לעיתים קרובות יותר |

שתי הדרכים עובדות. תיקייה אחת היא בחירה טובה לתוכניות גדולות, וקובץ אחד נוח לתוכניות קטנות.

## 4. בחירת שם

כברירת מחדל התוכנית נקראת על שם הקובץ שלכם (`main.exe`). כדי לתת לה שם יפה יותר, השתמשו ב-`--name`:

```bash
uv run pyinstaller --onefile --name Calculator main.py
```

זה יוצר את `dist\Calculator.exe`.

## 5. תוכניות עם ממשק גרפי (PySide6): בלי חלון טרמינל

אם בונים תוכנית PySide6 בדרך שהוצגה למעלה ולוחצים לחיצה כפולה על ה-`.exe`, נפתחים **שני** חלונות: החלון שלכם וחלון טרמינל שחור וריק מאחוריו. אם המשתמש סוגר את הטרמינל, גם התוכנית שלכם נסגרת.

לתוכניות עם ממשק גרפי הוסיפו `--windowed`, שאומר ל-PyInstaller לא לפתוח טרמינל:

```bash
uv run pyinstaller --onefile --windowed main.py
```

`--noconsole` ו-`-w` עושים בדיוק אותו דבר כמו `--windowed`, אז אתם עשויים לראות כל אחד מהם בדוגמאות ברשת.

שימו לב:

- עם `--windowed` אין טרמינל, אז כל מה שאתם מדפיסים עם `print()` לא מוצג בשום מקום. במקום זה, הציגו הודעות למשתמש בתוך החלון (בתווית או בתיבת הודעה).
- אם התוכנית קורסת כשהיא עולה, בנו אותה פעם אחת **בלי** `--windowed` והריצו אותה שוב: הטרמינל יישאר פתוח ויציג את הודעת השגיאה.
- אל תשתמשו ב-`--windowed` לתוכניות שעובדות בטרמינל (עם `input()` ו-`print()`). הן צריכות את הטרמינל.

## 6. הוספת אייקון

האייקון הוא התמונה של קובץ ה-`.exe` בסייר הקבצים (File Explorer) ובשורת המשימות. ב-Windows הוא חייב להיות קובץ **`.ico`**. אם יש לכם תמונה בפורמט אחר (כמו `.png`), המירו אותה בעזרת ממיר חינמי ברשת (חפשו "png to ico").

שימו את האייקון בתיקיית הפרויקט (למשל `app.ico`) והוסיפו `--icon`:

```bash
uv run pyinstaller --onefile --windowed --icon=app.ico main.py
```

> Windows זוכר אייקונים, אז לפעמים סייר הקבצים ממשיך להציג את האייקון הישן אחרי שבניתם מחדש. שנו את השם של ה-`.exe` או העתיקו אותו לתיקייה אחרת, ותראו את החדש.

### האייקון של החלון עצמו

`--icon` קובע את האייקון של קובץ ה-`.exe`. האייקון הקטן בפינה השמאלית העליונה של חלון ה-PySide6 שלכם נקבע בנפרד, בקוד, עם `setWindowIcon`:

```python
from pathlib import Path
from PySide6.QtGui import QIcon

HERE = Path(__file__).parent      # the folder this file is in

    def initUI(self):
        self.setWindowTitle("Calculator")
        self.setWindowIcon(QIcon(str(HERE / "app.ico")))
```

אחר כך אמרו ל-PyInstaller לארוז את קובץ האייקון יחד עם התוכנית, בעזרת `--add-data` (החלק שאחרי ה-`:` הוא התיקייה שבה הוא יישב בתוך התוכנית, ו-`.` פירושו "ליד התוכנית"):

```bash
uv run pyinstaller --onefile --windowed --icon=app.ico --add-data "app.ico:." main.py
```

אותו דבר נכון לכל קובץ אחר שהתוכנית שלכם טוענת, כמו תמונות או צלילים: ארזו כל אחד מהם (או תיקייה שלמה, למשל `--add-data "images:images"`) עם `--add-data`, ובנו את הנתיב שלו מ-`Path(__file__).parent` כמו למעלה. נתיב כמו `"app.ico"` לבד עובד כשמריצים את התוכנית מ-VS Code, אבל לא ב-`.exe`, כי שם התוכנית לא מתחילה לרוץ בתיקיית הפרויקט שלכם.

## סיכום

| מה אתם רוצים | הוסיפו את זה |
|---|---|
| תיקייה אחת (ברירת מחדל) | כלום |
| קובץ `.exe` אחד | `--onefile` |
| שם אחר לתוכנית | `--name Calculator` |
| בלי חלון טרמינל (תוכניות עם ממשק גרפי, PySide6) | `--windowed` (או `--noconsole`, `-w`) |
| אייקון ל-`.exe` | `--icon=app.ico` |
| אריזת קובץ שהתוכנית טוענת | `--add-data "app.ico:."` |

בנייה טיפוסית של תוכנית PySide6:

```bash
uv run pyinstaller --onefile --windowed --name Calculator --icon=app.ico --add-data "app.ico:." main.py
```

התוצאה נמצאת בתיקייה `dist`.
