# צבעים

כל צבע על המסך בנוי מ**שלושה אורות**: **א**דום (**R**ed), **י**רוק (**G**reen) ו**כ**חול (**B**lue). לכל נקודה קטנה במסך (פיקסל) יש את שלושתם, והיא מדליקה כל אחד מהם קצת או הרבה. ערבוב שלושת האורות בעוצמות שונות יוצר כל צבע שאתם רואים.

![אור אדום, ירוק וכחול מתערבבים: אדום + ירוק = צהוב, אדום + כחול = מג'נטה, ירוק + כחול = ציאן, שלושתם = לבן](content/images/pyside_colors_rgb_mix_he.png)

## 1. שלושה מספרים

ב-PySide6 כותבים צבע כ-`rgb(red, green, blue)`. כל מספר אומר **כמה חזק** האור הזה:

* `0` אומר שהאור **כבוי**.
* `255` אומר שהאור **דולק לגמרי**.
* כל מספר באמצע אומר שהוא דולק חלקית.

```python
label.setStyleSheet("color: rgb(255, 0, 0);")              # only red: red
label.setStyleSheet("background-color: rgb(255, 255, 0);") # red + green: yellow
```

הסדר הוא תמיד **אדום, ירוק, כחול**. `rgb(0, 0, 255)` הוא כחול, לא אדום.

לכל מספר יש 256 ערכים (0 עד 255), ולכן יש 256 × 256 × 256 = **16,777,216** צבעים.

## 2. איך לחשוב על זה

![אדום שמתחזק, גווני אפור משחור ללבן וכמה צבעים מעורבבים, כל אחד עם מספרי ה-rgb שלו](content/images/pyside_colors_swatches_he.png)

* **הכול כבוי** זה שחור: `rgb(0, 0, 0)`. **הכול דולק** זה לבן: `rgb(255, 255, 255)`.
* **שלושתם שווים** זה אפור. מספרים גדולים יותר נותנים אפור בהיר יותר: `rgb(64, 64, 64)` הוא אפור כהה, `rgb(192, 192, 192)` הוא אפור בהיר.
* **מספרים גדולים יותר = צבע בהיר יותר.** `rgb(128, 0, 0)` הוא אדום כהה, `rgb(255, 0, 0)` הוא אדום בוהק.
* **המספר הגדול מנצח.** ב-`rgb(255, 165, 0)` האדום הכי חזק, עם לא מעט ירוק, ולכן זה כתום.
* כדי לקבל צבע **חיוור** יותר, מעלים את המספרים הקטנים: `rgb(255, 0, 0)` הוא אדום, `rgb(255, 192, 203)` הוא ורוד.

כמה צבעים להתחיל מהם:

| צבע | rgb |
|---|---|
| שחור | `rgb(0, 0, 0)` |
| לבן | `rgb(255, 255, 255)` |
| אפור | `rgb(128, 128, 128)` |
| אדום | `rgb(255, 0, 0)` |
| ירוק | `rgb(0, 255, 0)` |
| כחול | `rgb(0, 0, 255)` |
| צהוב | `rgb(255, 255, 0)` |
| ציאן (תכלת) | `rgb(0, 255, 255)` |
| מג'נטה | `rgb(255, 0, 255)` |
| כתום | `rgb(255, 165, 0)` |
| סגול | `rgb(128, 0, 128)` |
| ורוד | `rgb(255, 192, 203)` |
| חום | `rgb(139, 69, 19)` |

## 3. צבעים ממשתנים

שלושת המספרים הם פשוט מספרים, אז הקוד שלכם יכול לבחור אותם. בונים את המחרוזת בעזרת f-string:

```python
import random

def change_color():
    r = random.randint(0, 255)
    g = random.randint(0, 255)
    b = random.randint(0, 255)
    label.setStyleSheet(f"background-color: rgb({r}, {g}, {b});")
    label.setText(f"rgb({r}, {g}, {b})")

button.clicked.connect(change_color)
```

כל לחיצה צובעת את התווית בצבע אקראי חדש ומציגה את המספרים שלו.

## 4. צבעי Hex

בקובצי עיצוב, ובמיוחד בקובצי QSS, תראו הרבה צבעים כמו `#FF8000`. אלה **אותם שלושה מספרים**, כתובים בבסיס 16 (הקסדצימלי) במקום בבסיס 10:

```text
#FF8000
 RR GG BB
 FF = 255   red
 80 = 128   green
 00 = 0     blue

#FF8000 is the same as rgb(255, 128, 0)
```

שתי ספרות hex לכל אור, באותו סדר: אדום, ירוק, כחול. `00` זה כבוי, `FF` זה דולק לגמרי.

```css
QPushButton {
    background-color: #2563eb;   /* the same as rgb(37, 99, 235) */
    color: #ffffff;              /* the same as rgb(255, 255, 255) */
}
```

שתי הדרכים עובדות בכל מקום בעיצוב של PySide6, ואפשר לערבב ביניהן באותו קובץ. כדי להפוך את המספרים שלכם ל-hex בפייתון: `f"#{r:02X}{g:02X}{b:02X}"`.

* כל מספר חייב להיות בין `0` ל-`255`.
* הסדר הוא תמיד אדום, ירוק, כחול.
