# * מה שאנחנו צריכים לזכור

1. Python היא **שפת תכנות** רב-גונית שנמצאת בשימוש נרחב במגוון תחומים, כולל פיתוח אתרים, ניתוח נתונים, בינה מלאכותית, חישוב מדעי ועוד.

2. תכנות ב-Python הוא מהיר, אבל **מהירות הריצה** שלה עלולה להיות **איטית יותר** בהשוואה לשפות כמו C או C++, כי היא שפה מפורשת (interpreted). אפשר למתן את זה במידה מסוימת בעזרת ספריות מותאמות לביצועים, או על ידי מימוש החלקים הקריטיים לביצועים בשפות אחרות.

3. אפשר להשתמש ב-Python בקובץ ".py" ובקובץ ".ipynb" (Jupyter Notebook). Jupyter Notebook משמש לחישוב אינטראקטיבי, לחקירת נתונים ולהצגה ויזואלית שלהם, ולכן הוא פופולרי במדעי הנתונים ובמחקר. קבצי py משמשים לכתיבת סקריפטים ומודולים שיכולים לרוץ כסקריפט או כתוכנית עצמאית.

4. אנחנו צריכים לזכור את כל החומר מהטקסט **Python Basics** ומהטקסט **Global Variables**. אפשר להיעזר בבוט כדי לעשות את זה.

5. Python יכולה לכתוב לקבצי טקסט ולקרוא מהם, והקוד די פשוט. אנחנו משתמשים בפקודה **with** כדי לוודא שהקבצים נסגרים כמו שצריך אחרי שסיימנו איתם. הפקודה **with** משמשת גם למשאבים אחרים שעוד לא למדנו עליהם.

6. אפשר לקרוא את כל קובץ הטקסט לתוך מחרוזת אחת, או להשתמש בלולאה ולקרוא אותו שורה אחרי שורה.

7. יש כמה סוגים של פורמטים לקבצי טקסט, ואחד מהם הוא **קובץ CSV (.csv)**.
   - **קבצי טקסט פשוט (.txt)**: מכילים טקסט ללא עיצוב, והם הסוג הפשוט ביותר של קובץ טקסט.
   - **קבצי CSV (.csv)**: קבצים של ערכים מופרדים בפסיקים (Comma-separated values), שמשמשים לנתונים בטבלה.

   אם ניצור קובץ .csv ונבקש ממערכת ההפעלה לפתוח אותו, בדרך כלל הוא ייפתח ב-excel והנתונים יחולקו לתאים נפרדים לפי הפסיקים.
