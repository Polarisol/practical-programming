# כללי .gitignore

כל שורה ב-`.gitignore` היא כלל. Git לא עוקב אחרי קבצים שמתאימים לכלל.

**מתעלמים מ:** קבצים שנוצרים אוטומטית (`.venv`, `__pycache__/`), נתונים ופלט גדולים (`data/`, `output/`) וסודות (`.env`). **לעולם אל תבצעו commit לסיסמאות או למפתחות API.**

## הכללים

| כלל | מתעלם מ |
|------|---------|
| `notes.txt` | כל קובץ או תיקייה בשם הזה, בכל תיקייה |
| `*.csv` | כל קובץ שמסתיים ב-`.csv` (`*` = כל טקסט) |
| `output/` | כל **תיקייה** בשם `output` (`/` בסוף = תיקיות בלבד) |
| `/config.py` | רק `config.py` שבתיקייה הראשית (`/` בהתחלה = מכאן) |
| `logs/**` | כל מה שבתוך `logs`, בכל עומק |
| `!keep.csv` | **חריג**: לא להתעלם מהקובץ הזה |
| `# text` | הערה |

הכלל המתאים **האחרון** קובע, ולכן חריג בא אחרי הכלל שהוא מבטל:

```gitignore
*.csv
!students.csv
```

## כבר ביצעתם commit? הפסיקו את המעקב

`.gitignore` משפיע רק על קבצים ש-git עוד לא עוקב אחריהם. לקובץ שכבר ביצעתם לו commit, הוסיפו אותו ל-`.gitignore`, הריצו את הפקודה הזו ובצעו commit:

```bash
git rm --cached secrets.txt     # the file stays on your computer
```

> סיסמה שהגיעה ל-GitHub נשארת בהיסטוריה. החליפו אותה.
