# כמה טוב המודל שלי?

אימנתם מודל שמסתכל על תמונה ואומר "חתול" או "כלב". איך יודעים אם הוא טוב? התשובה המתבקשת היא "לספור כמה פעמים הוא צודק". זו התחלה, אבל היא מסתירה הרבה: **אילו** טעויות המודל עושה? הוא מחמיץ חתולים, או קורא לכלבים חתולים? בהרבה בעיות אמיתיות לשתי הטעויות האלה יש מחיר שונה מאוד.

**מטריצת בלבול** (Confusion Matrix) עונה על זה. זו טבלה קטנה שממיינת כל חיזוי לאחת מארבע משבצות, ומארבעת המספרים האלה מקבלים את המדדים שכולם משתמשים בהם כדי לשפוט מסווג: **Accuracy**, **Precision**, **Recall** ו-**F1-score**.

## מטריצת הבלבול

מטריצת בלבול היא טבלה המסכמת את ביצועי האלגוריתם בסיווג של דוגמאות לקטגוריות שונות. היא נפוצה בעיקר בבעיות **סיווג בינארי** (שתי קטגוריות), אך אפשר להרחיב אותה גם למספר קטגוריות גדול יותר.

בסיווג בינארי קוראים לקטגוריה אחת **חיובי** ולשנייה **שלילי**. "חיובי" לא אומר "טוב". זו פשוט הקטגוריה שאנחנו מחפשים: חתול, חולה, הודעת ספאם, הונאה. מטריצת הבלבול בנויה אז מ-4 תאים:

![טבלה של 2 על 2. השורות הן מה שנכון באמת (חיובי או שלילי) והעמודות הן מה שהמודל אמר. True Positive ו-True Negative, על האלכסון, ירוקים: המודל צדק. False Negative ו-False Positive אדומים: המודל טעה](content/images/ml_confusion_matrix.svg)

1. **True Positive (TP)**: דוגמאות שחזינו כחיוביות והן אכן חיוביות במציאות.
2. **False Positive (FP)**: דוגמאות שחזינו כחיוביות אך למעשה הן שליליות במציאות. נקרא גם **Type I error**, או אזעקת שווא.
3. **False Negative (FN)**: דוגמאות שחזינו כשליליות אך הן חיוביות במציאות. נקרא גם **Type II error**, או החמצה.
4. **True Negative (TN)**: דוגמאות שחזינו כשליליות והן אכן שליליות במציאות.

דרך קלה לזכור את השמות: המילה השנייה (Positive / Negative) היא **מה שהמודל אמר**, והמילה הראשונה (True / False) היא **האם הוא צדק**.

מטריצת הבלבול מאפשרת לנו להפיק מדדים שונים, וכל אחד מהם מתאר את איכות המודל מזווית אחרת.

## Accuracy (דיוק)

**Accuracy** הוא היחס בין כמות התחזיות הנכונות (חיוביות נכונות + שליליות נכונות) לבין כלל הדוגמאות.

```math
\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}
```

ככל שערך זה גבוה, משמע שהמודל צודק ביותר מהתחזיות שלו. עם זאת, לעיתים Accuracy עלול להטעות אם יש **חוסר איזון** גדול בין הקטגוריות, למשל אם יש הרבה יותר דוגמאות שליליות מחיוביות.

דמיינו 1,000 מטופלים, ורק 10 מהם חולים. "מודל" עצל שתמיד אומר "בריא" צודק ב-990 מהם: **Accuracy של 99%**! ובכל זאת הוא לא מצא אף חולה אחד. בגלל זה צריך את המדדים הבאים.

## Precision (דיוק חיובי)

**Precision** בודק: מתוך כל הדוגמאות **שחזינו כחיוביות**, כמה מהן באמת חיוביות במציאות?

```math
\text{Precision} = \frac{TP}{TP + FP}
```

כאשר הערך גבוה, המשמעות היא שכמעט ולא "האשמנו חפים מפשע" (מעט FP): כשהמודל אומר "חיובי", אפשר לסמוך עליו. כלומר, המודל לא מסווג הרבה שליליים בטעות כחיוביים.

Precision חשוב במיוחד כשאזעקת שווא יקרה. מסנן ספאם צריך Precision גבוה: לשלוח מייל חשוב לתיקיית הספאם גרוע יותר מלהעביר הודעת ספאם אחת לתיבה.

## Recall (רגישות/שליפה)

**Recall** (נקרא לעיתים Sensitivity) בודק: מתוך כל הדוגמאות **החיוביות שקיימות באמת**, כמה מהן זיהינו כחיוביות?

```math
\text{Recall} = \frac{TP}{TP + FN}
```

כשהערך גבוה, המשמעות היא שהמודל כמעט לא מפספס דוגמאות שהן חיוביות במציאות (מעט FN).

Recall חשוב במיוחד כשהחמצה יקרה. בדיקה למחלה קשה צריכה Recall גבוה: לשלוח חולה הביתה גרוע בהרבה מלבקש מאדם בריא לעשות בדיקה נוספת.

**Precision ו-Recall מושכים לכיוונים הפוכים.** מודל שאומר "חיובי" על הכול מקבל Recall מושלם (הוא לא מפספס כלום) ו-Precision גרוע. מודל שאומר "חיובי" רק כשהוא בטוח ב-100% מקבל Precision מצוין ו-Recall חלש. הבחירה ביניהם תלויה בשאלה איזו טעות עולה יותר.

## F1-score

**F1-score** הוא ממוצע הרמוני בין Precision ל-Recall, ומספק מדד אחד שמאזן בין שניהם.

```math
F1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
```

למה ממוצע הרמוני ולא ממוצע רגיל? כי הוא מעניש ערך נמוך. למודל עם Precision של 1.0 ו-Recall של 0.0 יש ממוצע רגיל של 0.5, אבל F1 של **0**. כדי לקבל F1 גבוה, שניהם צריכים להיות גבוהים.

ה-F1-score מועיל במיוחד כשהמודל שלנו צריך לשמור על איזון בין אי "האשמה" שלילי לבין אי פספוס חיובי, והוא רגיש יותר מ-Accuracy למקרים של חוסר איזון בין הקטגוריות.

## דוגמה פשוטה

נניח שיש לנו 10 בעלי חיים: 4 חתולים ו-6 כלבים. נשתמש במודל שמנסה לחזות אם בעל חיים הוא "חתול" (חיובי) או "כלב" (שלילי). נניח שהמודל נתן את התחזיות הבאות:

- מתוך 4 החתולים, 3 זוהו נכון כחתולים (TP = 3), ו-1 חתול זוהה בטעות ככלב (FN = 1).
- מתוך 6 הכלבים, 2 זוהו בטעות כחתולים (FP = 2), ו-4 זוהו נכון ככלבים (TN = 4).

כעת נרכיב את מטריצת הבלבול:

![מטריצת הבלבול של מודל החתולים והכלבים. אמיתי חתול: TP = 3 חתולים שזוהו, FN = 1 חתול שהוחמץ. אמיתי כלב: FP = 2 כלבים שנקראו חתולים, TN = 4 כלבים שזוהו. נכונים: 7 מתוך 10, שגיאות: 3](content/images/ml_confusion_cats_dogs.svg)

והמדדים:

- **Accuracy**: `(TP + TN) / (TP + TN + FP + FN) = (3 + 4) / (3 + 4 + 2 + 1) = 7 / 10 = 70%`
- **Precision**: `TP / (TP + FP) = 3 / (3 + 2) = 3 / 5 = 60%`
- **Recall**: `TP / (TP + FN) = 3 / (3 + 1) = 3 / 4 = 75%`
- **F1-score**: `2 × (0.6 × 0.75) / (0.6 + 0.75) = 0.9 / 1.35 ≈ 0.67 = 67%`

דרך הדוגמה הזאת אפשר לראות איך כל מדד נותן זווית אחרת על ביצועי המודל:

- **Accuracy** מסתכל על כלל התחזיות: המודל צדק לגבי 7 מתוך 10 בעלי החיים.
- **Precision** מסתכל על דיוק החיזוי החיובי: מתוך 5 בעלי החיים שהמודל קרא להם "חתול", רק 3 היו באמת חתולים.
- **Recall** מסתכל על יכולת "לתפוס" את כל החתולים: המודל מצא 3 מתוך 4 החתולים.
- **F1** הוא האיזון בין Precision ל-Recall.

## לחשב את זה בפייתון

הספירה פשוטה מספיק כדי לעשות אותה לבד. הנה התוויות האמיתיות והתחזיות של המודל עבור 10 בעלי החיים:

```python
actual    = ["cat", "cat", "cat", "cat", "dog", "dog", "dog", "dog", "dog", "dog"]
predicted = ["cat", "cat", "cat", "dog", "cat", "cat", "dog", "dog", "dog", "dog"]

positive = "cat"
tp = fp = fn = tn = 0
for a, p in zip(actual, predicted):
    if p == positive and a == positive:
        tp += 1
    elif p == positive:
        fp += 1
    elif a == positive:
        fn += 1
    else:
        tn += 1

accuracy = (tp + tn) / len(actual)
precision = tp / (tp + fp)
recall = tp / (tp + fn)
f1 = 2 * precision * recall / (precision + recall)

print(f"TP={tp} FP={fp} FN={fn} TN={tn}")
print(f"Accuracy:  {accuracy:.0%}")
print(f"Precision: {precision:.0%}")
print(f"Recall:    {recall:.0%}")
print(f"F1-score:  {f1:.0%}")
```

```
TP=3 FP=2 FN=1 TN=4
Accuracy:  70%
Precision: 60%
Recall:    75%
F1-score:  67%
```

בפרויקטים אמיתיים בדרך כלל נותנים לספרייה **scikit-learn** לעשות את זה (`uv add scikit-learn`). `confusion_matrix` בונה את הטבלה, ו-`classification_report` מדפיס Precision, Recall ו-F1 לכל קטגוריה:

```python
from sklearn.metrics import confusion_matrix, classification_report

print(confusion_matrix(actual, predicted, labels=["cat", "dog"]))
print(classification_report(actual, predicted))
```

## סיכום

| מדד | על איזו שאלה הוא עונה | נוסחה |
|-----|------------------------|-------|
| Accuracy | כמה פעמים המודל צודק? | `(TP + TN) / all` |
| Precision | כשהוא אומר "חיובי", האם הוא צודק? | `TP / (TP + FP)` |
| Recall | מכל החיוביים האמיתיים, כמה הוא מצא? | `TP / (TP + FN)` |
| F1-score | מספר אחד שמאזן בין Precision ל-Recall | `2 × P × R / (P + R)` |

- לעולם אל תסמכו רק על Accuracy, במיוחד כשקטגוריה אחת נדירה בהרבה מהשנייה.
- שאלו איזו טעות גרועה יותר **בבעיה שלכם**: אזעקת שווא (שימו לב ל-Precision) או החמצה (שימו לב ל-Recall).
