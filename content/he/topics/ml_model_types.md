# סוגי מודלים

מודל של למידת מכונה הוא תוכנה שלומדת מנתונים, במקום לפעול לפי כללים שכתבנו ביד. אף אחד לא כותב `if ears_are_pointy and weight < 6: return "cat"`. אנחנו מראים לתוכנה הרבה נתונים, והיא מוצאת את הכללים בעצמה.

אבל "ללמוד מנתונים" יכול להיות דברים שונים מאוד. השאלה הגדולה היא: **מה הנתונים אומרים למודל?** האם כל דוגמה מגיעה עם התשובה הנכונה? האם אף דוגמה לא מגיעה עם תשובה? או שהמודל מגלה רק אחר כך אם מה שהוא עשה היה טוב או רע? התשובה מחלקת את למידת המכונה לשלוש משפחות עיקריות:

1. **למידה מונחית** (Supervised Learning): לומדים מדוגמאות שמגיעות עם תשובות.
2. **למידה לא מונחית** (Unsupervised Learning): מוצאים מבנה בנתונים שאין להם תשובות.
3. **למידת חיזוק** (Reinforcement Learning): לומדים מניסוי וטעייה, מתגמולים ומעונשים.

## למידה מונחית (Supervised Learning)

בלמידה מונחית לכל דוגמת אימון יש **תווית** (Label): התשובה הנכונה. זה כמו ללמוד עם מורה שיש לו את דף התשובות. אנחנו מראים למודל אלפי תמונות, שכל אחת מסומנת "חתול" או "כלב", והוא לומד מה מבדיל ביניהן. אחר כך נותנים לו תמונה חדשה שהוא לא ראה אף פעם, והוא חוזה את התווית.

![שני חלונות. בצד ימין, נתוני האימון: עיגולים כתומים עם התווית חתול וריבועים כחולים עם התווית כלב, וביניהם קו מקווקו שהמודל למד. בצד שמאל, נקודה חדשה עם סימן שאלה נופלת בצד של החתולים, ולכן המודל אומר: חתול](content/images/ml_types_supervised_he.svg)

הדוגמאות נקראות **קלטים** (Inputs, בדרך כלל `X`) והתשובות נקראות **תוויות** או **ערכי מטרה** (Labels / Targets, בדרך כלל `y`). המודל לומד פונקציה שמקבלת `X` ומחזירה `y`.

בעיות של למידה מונחית מתחלקות לשני סוגים:

- **סיווג** (Classification): התשובה היא קטגוריה. חתול או כלב? ספאם או לא ספאם? איזו ספרה מצוירת כאן? האם הגידול שפיר או ממאיר?
- **רגרסיה** (Regression): התשובה היא מספר. בכמה תימכר הדירה הזאת? כמה גלידות נמכור מחר? כמה זמן תיקח הנסיעה?

**למה משתמשים בה:** מסנני ספאם, זיהוי פנים בגלריית התמונות בטלפון, קריאת ספרות בכתב יד (נסו את הסימולציה בעמוד הזה, היא מודל של למידה מונחית), אבחון רפואי מצילומים, זיהוי הונאות בכרטיסי אשראי, חיזוי מחירים, תרגום והמרת דיבור לטקסט.

**מה היא יכולה לעשות, ומה היא צריכה:** למידה מונחית היא הסוג הנפוץ ביותר של למידת מכונה, ובדרך כלל המדויק ביותר, כי המודל יודע בדיוק למה הוא מכוון. ומכיוון שיש לנו את התשובות הנכונות, אפשר למדוד כמה המודל טוב (ראו את הפריט הבא, "כמה טוב המודל שלי?"). הבעיה היא שהיא צריכה **הרבה נתונים מתויגים**, ותיוג עולה ביוקר: מישהו צריך לשבת ולסמן אלפי תמונות, או שרופא צריך לאבחן אלפי צילומים. המודל גם טוב רק כמו התוויות שלו. אם התוויות שגויות או מוטות, המודל לומד גם את הטעויות.

### טעימה ב-Python

הנה מסווג קטנטן עם **scikit-learn** (`uv add scikit-learn`). כל חיה מתוארת לפי המשקל והגובה שלה, ואנחנו נותנים למודל את התשובות:

```python
from sklearn.neighbors import KNeighborsClassifier

# each animal: [weight in kg, height in cm]
X = [[4, 25], [5, 23], [3, 22], [30, 60], [25, 55], [35, 65]]
y = ["cat", "cat", "cat", "dog", "dog", "dog"]   # the answers

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X, y)                     # learn from examples AND answers

print(model.predict([[6, 26], [28, 58]]))
```

```
['cat' 'dog']
```

שימו לב ל-`fit(X, y)`: המודל מקבל גם את הדוגמאות וגם את התשובות.

## למידה לא מונחית (Unsupervised Learning)

בלמידה לא מונחית **אין תוויות** בכלל. אנחנו נותנים למודל ערימה של נתונים ושואלים: "מה אתה מוצא כאן?" אין מורה ואין דף תשובות. המודל מחפש דפוסים, קבוצות ומבנה בעצמו.

![שני חלונות. בצד ימין, נקודות אפורות בלי תוויות, שיושבות בשלושה ענני נקודות. בצד שמאל, אותן נקודות צבועות בשלושה צבעים, כל ענן מוקף ומסומן קבוצה 1, קבוצה 2 וקבוצה 3. אף אחד לא אמר למודל מהן הקבוצות](content/images/ml_types_unsupervised_he.svg)

המשימות הנפוצות ביותר בלמידה לא מונחית הן:

- **אשכול** (Clustering): לחלק את הנתונים לקבוצות של פריטים דומים. חנות אונליין יכולה לחלק את הלקוחות שלה לקבוצות לפי האופן שבו הם קונים, בלי לדעת מראש מהן הקבוצות.
- **זיהוי חריגות** (Anomaly Detection): ללמוד איך נראה "נורמלי", ולסמן כל דבר שלא מתאים. כניסה מוזרה לחשבון בשלוש לפנות בוקר ממדינה אחרת, או מכונה במפעל שמתחילה לרטוט אחרת.
- **הורדת ממדים** (Dimensionality Reduction): לדחוס נתונים עם הרבה עמודות למעט עמודות, ולשמור על מה שחשוב. זה עוזר לצייר נתונים רב-ממדיים על מסך דו-ממדי, או להאיץ מודלים אחרים.

**למה משתמשים בה:** פילוח לקוחות לשיווק, קיבוץ כתבות חדשות על אותו אירוע, המלצות על מוצרים ("מי שקנה את זה קנה גם..."), איתור הונאות ומתקפות סייבר, דחיסת תמונות, וחקירה של מאגר נתונים חדש לפני שיודעים מה לשאול עליו.

**מה היא יכולה לעשות, ומה לא:** היתרון הגדול שלה הוא שהיא עובדת על **נתונים גולמיים**, ונתונים גולמיים הם זולים ונמצאים בכל מקום. היא יכולה לגלות דפוסים שאף אחד לא חשב לחפש. אבל המודל לא יודע מה הקבוצות **אומרות**. הוא יגיד לכם "500 הלקוחות האלה דומים", ואדם צריך להסתכל עליהם ולהחליט שאלה "סטודנטים שקונים בלילה". גם קשה יותר לשפוט אותה: כשאין תשובות נכונות, אין ציון פשוט שאומר אם החלוקה "נכונה".

### טעימה ב-Python

כאן אנחנו נותנים ל-**KMeans** תשעה לקוחות ומבקשים ממנו למצוא שלוש קבוצות. שימו לב שאין `y`:

```python
from sklearn.cluster import KMeans

# customers: [visits per month, money spent per visit]
X = [[1, 20], [2, 25], [1, 22],      # come rarely, spend a little
     [9, 25], [10, 20], [8, 22],     # come often, spend a little
     [2, 90], [1, 95], [3, 100]]     # come rarely, spend a lot

model = KMeans(n_clusters=3, n_init=10, random_state=0)
model.fit(X)                        # learn from the examples only: no y!

print(model.labels_)
```

```
[2 2 2 0 0 0 1 1 1]
```

המודל שם כל לקוח בקבוצה (0, 1 או 2) ומצא בדיוק את שלושת הסוגים שהיו לנו בראש. למספרי הקבוצות עצמם אין משמעות. לתת להן שמות זה התפקיד שלנו.

## למידת חיזוק (Reinforcement Learning)

בלמידת חיזוק (RL) אין בכלל מאגר של דוגמאות. במקום זה יש **סוכן** (Agent), הלומד, שחי בתוך **סביבה** (Environment): משחק, סימולציה, העולם האמיתי. הסוכן מבצע **פעולה** (Action), הסביבה משתנה, והסוכן מקבל **תגמול** (Reward): מספר שאומר כמה זה היה טוב. תגמול חיובי הוא כמו פרס, ותגמול שלילי הוא כמו עונש.

![לולאה בין שתי קופסאות. הסוכן, הלומד, שולח פעולה לסביבה, המשחק או העולם. הסביבה מחזירה תגמול, חיובי או שלילי, ומצב חדש. הסוכן חוזר על הלולאה הזאת הרבה פעמים ולומד אילו פעולות מביאות הכי הרבה תגמול](content/images/ml_types_reinforcement_he.svg)

הסוכן חוזר על הלולאה הזאת אלפי או מיליוני פעמים. בהתחלה הוא פועל כמעט באקראי. לאט לאט הוא לומד **מדיניות** (Policy): איזו פעולה לבחור בכל מצב, כך ש**סך התגמולים לאורך זמן** יהיה גדול ככל האפשר. בדיוק ככה מלמדים כלב תרגיל, או ככה למדתם לרכוב על אופניים: אף אחד לא נתן לכם טבלה של תשובות נכונות, ניסיתם, נפלתם ותיקנתם.

שני רעיונות הופכים את למידת החיזוק למיוחדת:

- **תגמול מאוחר**: בשחמט מגלים רק בסוף אם ניצחתם. הסוכן צריך להבין איזה מבין 40 המהלכים שלו הביא את הניצחון.
- **חקירה מול ניצול** (Exploration vs. Exploitation): האם הסוכן צריך לעשות את מה שעבד עד עכשיו (ניצול), או לנסות משהו חדש שאולי יהיה טוב עוד יותר (חקירה)? מעט מדי חקירה, והוא נתקע על אסטרטגיה "מספיק טובה". יותר מדי, והוא אף פעם לא משתמש במה שלמד.

**למה משתמשים בה:** משחקים (AlphaGo ניצח את אלוף העולם ב-Go, וסוכני RL משחקים ב-Atari וב-StarCraft ברמה על-אנושית), ללמד רובוטים ללכת ולתפוס חפצים, החלטות של מכוניות אוטונומיות, שליטה בקירור של חוות שרתים כדי לחסוך באנרגיה, וכוונון של צ'אטבוטים כמו ChatGPT, ‏Gemini ו-Claude בעזרת משוב מבני אדם (RLHF), כדי שהתשובות שלהם יהיו מועילות יותר.

**מה היא יכולה לעשות, ומה היא צריכה:** למידת חיזוק יכולה לפתור בעיות שאף אחד לא יודע מראש מה התשובה הנכונה בהן, והיא יכולה למצוא אסטרטגיות שמפתיעות אפילו מומחים. אבל היא צריכה **מספר עצום של ניסיונות**, ולכן בדרך כלל מאמנים אותה בסימולציה ולא על רובוט אמיתי שעלול להישבר. היא גם רגישה מאוד לאופן שבו מגדירים את התגמול: סוכן ימצא בשמחה "פרצה" שאוספת תגמול בלי לעשות את מה שבאמת רצינו.

### טעימה ב-Python

הפעם לא צריך ספרייה. סוכן עומד מול שלוש מכונות מזל. הוא לא יודע שהן משלמות ב-20%, 50% ו-80% מהפעמים. יש לו 1,000 ניסיונות להבין איזו מהן הכי טובה. ברוב הפעמים הוא בוחר את המכונה הכי טובה עד עכשיו (ניצול), וב-10% מהפעמים הוא בוחר מכונה אקראית (חקירה):

```python
import random

chances = [0.2, 0.5, 0.8]   # hidden from the agent: how often each machine pays
value = [0.0, 0.0, 0.0]     # what the agent believes each machine is worth
tries = [0, 0, 0]

for step in range(1000):
    if random.random() < 0.1:               # explore: try something random
        action = random.randrange(3)
    else:                                   # exploit: pick the best so far
        action = value.index(max(value))
    reward = 1 if random.random() < chances[action] else 0
    tries[action] += 1
    value[action] += (reward - value[action]) / tries[action]

print("tries:", tries)
print("learned values:", [round(v, 2) for v in value])
```

```
tries: [36, 76, 888]
learned values: [0.19, 0.5, 0.78]
```

המספרים שלכם יהיו קצת שונים בכל הרצה, אבל הסוכן תמיד מגיע למצב שבו הוא משקיע כמעט את כל הניסיונות שלו במכונה הכי טובה, וההערכות שלו לגבי כמה כל מכונה משלמת קרובות לאמת. אף אחד לא אמר לו את התשובה: הוא למד רק מהתגמולים.

## סיכום

| | למידה מונחית | למידה לא מונחית | למידת חיזוק |
|---|---|---|---|
| מה המודל מקבל | דוגמאות **עם** תשובות | דוגמאות **בלי** תשובות | תגמולים על הפעולות שלו |
| מה הוא לומד | לחזות את התשובה לדוגמאות חדשות | קבוצות ודפוסים בנתונים | איזו פעולה לבחור בכל מצב |
| משימות אופייניות | סיווג, רגרסיה | אשכול, זיהוי חריגות | משחקים, רובוטים, בקרה |
| דוגמה | האם המייל הזה ספאם? | אילו לקוחות דומים זה לזה? | איך מנצחים בשחמט? |
| המחיר העיקרי | לתייג הרבה נתונים | להבין מה הוא מצא | המון ניסיונות, ותגמול טוב |

- שאלו קודם: **האם יש לי את התשובות הנכונות לנתונים שלי?** אם כן, זו כנראה בעיה של למידה מונחית. אם לא, למידה לא מונחית. אם ה"נתונים" הם תוצאה של הפעולות של המודל עצמו, זו למידת חיזוק.
- מערכות אמיתיות משלבות ביניהן לעיתים קרובות. צ'אטבוט לומד קודם מכמויות עצומות של טקסט לא מתויג, אחר כך מדוגמאות של תשובות טובות, ולבסוף מתגמולים שנותנים בני אדם.
