# * מה צריך לזכור

1. Git היא **מערכת לניהול גרסאות** (version control system) שמאפשרת לעקוב אחרי שינויים בקוד, לשתף פעולה עם אחרים ולנהל גרסאות שונות של הפרויקט.

2. Git מאפשרת לנו **לחזור אחורה בזמן**: לעבור על ההיסטוריה של כל קובץ ולשחזר גרסאות קודמות אם צריך.

3. Git מציגה לנו את כל ההיסטוריה של הפרויקט, כולל מי ביצע שינויים, אילו שינויים בוצעו ומתי הם בוצעו.

4. Git מאפשרת **שיתוף פעולה**: כמה אנשים יכולים לעבוד על אותו פרויקט בו-זמנית, והשינויים של התורמים השונים ממוזגים ביעילות.

5. צריך להבין מה התפקיד של הקובץ **`.gitignore`** ואיך משתמשים בו.

6. צריך לדעת לראות את השינויים שעשיתם, או שהבינה המלאכותית עשתה, דרך השילוב של git ב-VS Code.

7. צריך לדעת לבצע commit לשינויים, כולל כתיבת הודעות commit.
