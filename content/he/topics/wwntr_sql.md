# * מה צריך לזכור

1. **מסד נתונים** (database) שומר נתונים **בטבלאות**. כל **שורה** (row) היא רשומה אחת, וכל **עמודה** (column) היא סוג אחד של מידע עם טיפוס קבוע. **המפתח הראשי** (primary key, בדרך כלל `id`) הוא ייחודי לכל שורה, כך שתמיד אפשר להצביע על שורה אחת בדיוק.

2. **SQL** היא השפה שבה אנחנו מדברים עם מסד נתונים. אנחנו אומרים לו *מה* אנחנו רוצים, והוא כבר מבין *איך* להשיג את זה.

3. **SQLite** שומר את כל מסד הנתונים **בקובץ אחד**, והוא מגיע מובנה ב-Python בתור המודול `sqlite3`, כך שאין צורך להתקין שום דבר.

4. השלבים הבסיסיים ב-Python: `sqlite3.connect()` → `cursor()` → `execute()` → `fetchall()` / `fetchone()` → `commit()` (אחרי שינוי נתונים) → `close()`. ראו **התחברות למסד נתונים** (Connecting to a database) בפרק **יסודות SQL** (SQL Basics).

5. ארבע הפעולות הבסיסיות הן **CRUD**: יצירה (Create) = `INSERT`, קריאה (Read) = `SELECT`, עדכון (Update) = `UPDATE`, מחיקה (Delete) = `DELETE`. ראו **יסודות SQL** (SQL Basics).

6. **תמיד** כתבו `WHERE` ב-`UPDATE` וב-`DELETE`. בלעדיו, *כל* השורות בטבלה ישתנו או יימחקו!

7. `SELECT` היא הפקודה העשירה ביותר. זכרו את סדר החלקים שלה: `SELECT ... FROM ... WHERE ... GROUP BY ... HAVING ... ORDER BY ... LIMIT ...`. `WHERE` מסנן שורות **לפני** הקיבוץ, ו-`HAVING` מסנן את **הקבוצות**. ראו **קיבוץ עם GROUP BY ו-HAVING** (Grouping with GROUP BY and HAVING) בפרק **יסודות SQL** (SQL Basics).

8. **פונקציות צבירה** (aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) הופכות הרבה שורות לערך אחד.

9. כל סוג של דבר מקבל **טבלה משלו**, והטבלאות מחוברות ביניהן בעזרת מזהים (**מפתחות זרים**, foreign keys). **JOIN** מצרף יחד את השורות המתאימות מהטבלאות. לא צריך לזכור בעל פה כל סוג של JOIN; מספיק לדעת מה JOIN עושה ולחפש את הפרטים כשצריך. ראו **יותר מטבלה אחת: JOIN** (More than one table: JOIN) בפרק **יסודות SQL** (SQL Basics).

10. **הזרקת SQL** (SQL injection): אם אנחנו מדביקים קלט של משתמש לתוך שאילתה עם f-strings או עם `+`, משתמש יכול להקליד טקסט שמשנה את פקודת ה-SQL שלנו. **אף פעם** אל תבנו SQL מערכים חיצוניים בדרך הזו. תמיד השתמשו בסימני מקום `?` (placeholders) והעבירו את הערכים בנפרד בתור tuple: `cur.execute('... WHERE name = ?', (name,))`. ראו את הפרק **הזרקת SQL** (SQL Injection).

11. tuple עם ערך אחד צריך פסיק: `(name,)`. `(name)` הוא פשוט `name`.

12. **הפשטת SQL** (SQL abstraction): אנחנו לא מפזרים שאילתות SQL בכל הקוד. אנחנו יוצרים מחלקה אחת (למשל `Database`) שמתחברת למסד הנתונים ב-`__init__` ויש לה מתודות עם שמות ברורים, כמו `get_average_grade()`. **כל ה-SQL נמצא במחלקה הזו, ורק בה.** שאר הפרויקט רק קורא למתודות שלה. ראו את הפרק **הפשטת SQL** (SQL Abstraction).
