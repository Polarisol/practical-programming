# הזרקת SQL (SQL Injection)

## הבעיה

נניח שאנחנו נותנים למשתמש להקליד שם, ומחפשים אותו במסד הנתונים. ניסיון ראשון טבעי הוא להדביק את הטקסט של המשתמש לתוך מחרוזת ה-SQL:

```python
name = input('Name: ')
cur.execute(f"SELECT * FROM students WHERE name = '{name}'")   # DANGEROUS!
```

אם המשתמש מקליד `Roni`, מסד הנתונים מקבל:

```sql
SELECT * FROM students WHERE name = 'Roni'
```

הכול טוב. אבל מה אם המשתמש מקליד במקום זה את הטקסט הבא?

```
x' OR '1'='1
```

עכשיו הטקסט שהודבק לתוך השאילתה הופך ל:

```sql
SELECT * FROM students WHERE name = 'x' OR '1'='1'
```

`'1'='1'` תמיד אמת, ולכן השאילתה מחזירה **את כל הסטודנטים** בטבלה. המשתמש לא סתם נתן לנו שם. הוא **שינה את פקודת ה-SQL שלנו**.

זה נקרא **הזרקת SQL** (SQL injection): המשתמש "מזריק" SQL משלו לתוך השאילתה שלנו. משתמש זדוני יכול לנצל את זה כדי לראות נתונים שאסור לו לראות, להתחבר בלי סיסמה, או אפילו למחוק טבלאות שלמות. זו אחת מפרצות האבטחה הנפוצות ביותר בתוכנות אמיתיות.

> שורש הבעיה: מסד הנתונים לא יכול לדעת איזה חלק מהמחרוזת הוא **הפקודה שלנו** ואיזה חלק הוא **הנתונים של המשתמש**. הכול בשבילו מחרוזת אחת.

## הפתרון: ממלאי מקום `?`

במקום להדביק את הערך לתוך המחרוזת, שמים `?` במקום שבו הערך צריך להופיע, ומעבירים את הערכים בנפרד כ-tuple:

```python
name = input('Name: ')
cur.execute('SELECT * FROM students WHERE name = ?', (name,))   # safe
```

עכשיו הפקודה והנתונים מגיעים למסד הנתונים **בנפרד**. מסד הנתונים מתייחס לכל מה שנמצא ב-`name` כאל **נתונים רגילים**, ואף פעם לא כאל SQL. אם המשתמש מקליד `x' OR '1'='1`, מסד הנתונים פשוט מחפש סטודנט ששמו הוא ממש `x' OR '1'='1`, לא מוצא אף אחד, ושום דבר רע לא קורה.

כשיש יותר מערך אחד, משתמשים ב-`?` אחד לכל ערך, לפי הסדר:

```python
cur.execute('INSERT INTO students (name, grade, city) VALUES (?, ?, ?)',
            (name, grade, city))
```

> שימו לב לפסיק ב-`(name,)`: tuple עם איבר אחד צריך אותו. `(name)` בלי הפסיק הוא פשוט `name`.

## הכלל

**לעולם אל תבנו SQL עם f-strings, `+` או `.format()` מערכים שמגיעים מבחוץ** (מהמשתמש, מקובץ, מהאינטרנט). תמיד השתמשו ב-`?` והעבירו את הערכים בנפרד.

| ❌ לא בטוח | ✅ בטוח |
|----------|--------|
| `f"... WHERE name = '{name}'"` | `'... WHERE name = ?', (name,)` |
| `"... WHERE id = " + str(id)` | `'... WHERE id = ?', (id,)` |

בונוס: עם `?` אף פעם לא צריך לדאוג גם לגבי גרשיים. שם כמו `O'Brien` ישבור את הגרסה עם ה-f-string, אבל יעבוד מצוין עם `?`.
