# למה להשתמש ב-Git

בלי git, פרויקט בדרך כלל נראה בסוף כך: `main.py`, `main_old.py`, `main_works.py`, `main_final_REALLY.py`. אף אחד לא זוכר מה ההבדל ביניהם, והגרסה שעבדה אתמול כבר איננה. Git פותר את זה.

## מה git נותן לכם

- **לבטל כל דבר.** כל commit הוא תמונת מצב של כל הפרויקט. שברתם משהו? חזרו לגרסה האחרונה שעבדה, של קובץ אחד או של הכול.
- **לראות מה השתנה.** Git מראה לכם, שורה אחר שורה, מה שיניתם מאז ה-commit האחרון. זו הדרך המהירה ביותר למצוא את השינוי ששבר את הקוד.
- **לבדוק את העבודה של ה-AI.** כש-Copilot או AI אחר עורכים את הקבצים שלכם, git מראה לכם בדיוק מה הם שינו. בדקו, השאירו את מה שטוב, ובטלו את השאר בלחיצה אחת.
- **לנסות בלי לפחד.** נסו שינוי גדול על **ענף** (branch). אם הוא עובד, מזגו אותו. אם לא, זרקו אותו. הקוד שעובד לא נפגע.
- **היסטוריה של הפרויקט.** כל commit שומר מה השתנה, מתי ולמה (ההודעה שלכם). גם אחרי חודשים אפשר לראות איך הפרויקט התפתח.
- **גיבוי ושיתוף.** דחפו (push) את ה-commits שלכם ל-**GitHub**, והפרויקט בטוח גם אם המחשב שלכם לא. משם אפשר להמשיך במחשב אחר, להגיש עבודה, או לעבוד על אותו פרויקט עם חברים.

## Git ו-GitHub הם לא אותו דבר

- **Git** הוא תוכנה במחשב שלכם ששומרת את ההיסטוריה. הוא עובד גם בלי אינטרנט.
- **GitHub** הוא אתר ששומר עותק של המאגר שלכם בענן, כדי שתוכלו לגבות, לשתף ולעבוד יחד.

מבצעים commit עם git במחשב, ודוחפים (push) ל-GitHub כשרוצים לעדכן את העותק שבענן.

> Git עוזר רק אם משתמשים בו. לפרויקט בלי commits אין היסטוריה לחזור אליה. התחילו לבצע commit מהיום הראשון.
