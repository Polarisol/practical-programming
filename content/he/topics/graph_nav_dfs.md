# DFS - חיפוש לעומק

## הרעיון

דמיינו שאתם חוקרים מערה עם הרבה מנהרות. אתם בוחרים מנהרה והולכים בה כמה שיותר רחוק. כשאתם מגיעים למבוי סתום, אתם חוזרים **אחורה** למקום האחרון שבו הייתה מנהרה שעוד לא ניסיתם, ונכנסים אליה. ממשיכים כך עד שראיתם את כל המנהרות.

זה **חיפוש לעומק** (Depth-First Search, או בקיצור DFS). הוא הולך קודם כול **לעומק**: הוא ממשיך להתקדם לשכן חדש כל עוד הוא יכול. רק כשהוא תקוע הוא חוזר אחורה (זה נקרא **backtracking**, או חזרה לאחור) ומנסה דרך אחרת.

## דוגמה

נתחיל שוב ב-`A`. החצים הסגולים מראים לאן DFS מתקדם, והמספרים השחורים מראים את סדר הביקורים:

![DFS על גרף הדוגמה. סדר הביקור הוא A, B, D, E, F, C, G](content/images/dfs_order.svg)

בואו נעקוב אחריו:

1. מתחילים ב-`A`. השכן הראשון שלו הוא `B`, אז הולכים ל-`B`.
2. מ-`B`, השכן החדש הראשון הוא `D`. הולכים ל-`D`.
3. `D` הוא מבוי סתום (השכן היחיד שלו, `B`, כבר בוקר). חוזרים **אחורה** ל-`B`.
4. ל-`B` עוד נשאר `E`. הולכים ל-`E`.
5. מ-`E`, הולכים ל-`F`.
6. מ-`F`, הולכים ל-`C`. עכשיו `C` הוא מבוי סתום (`A` ו-`F` כבר בוקרו). חוזרים ל-`F`, שגם איתו סיימנו, וחוזרים ל-`E`.
7. ל-`E` עוד נשאר `G`. הולכים ל-`G`. עכשיו ביקרנו בכל הצמתים.

הסדר הוא `A, B, D, E, F, C, G`. השוו אותו ל-BFS, שביקר ב-`A, B, C, D, E, F, G`: BFS הגיע ל-`C` שלישי, כי הוא נמצא במרחק צעד אחד בלבד מ-`A`. DFS הגיע אליו שישי, אחרי סיבוב ארוך מסביב לגרף.

## הקוד: רקורסיה

DFS מתאים בדיוק ל**רקורסיה**. "לבקר בצומת" פירושו: לסמן אותו, ואז לבקר בכל אחד מהשכנים שלו שעוד לא בוקר. כשקריאה מסתיימת, Python חוזרת אוטומטית לקריאה שלפניה. זה ה-backtracking, בחינם.

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F', 'G'],
    'F': ['C', 'E'],
    'G': ['E'],
}

def dfs(graph, node, visited=None):
    if visited is None:
        visited = []
    visited.append(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)   # go deeper before trying the next neighbour
    return visited

print(dfs(graph, 'A'))   # ['A', 'B', 'D', 'E', 'F', 'C', 'G']
```

> למה `visited=None` ולא `visited=[]`? רשימת ברירת מחדל ב-Python נוצרת רק **פעם אחת** ומשותפת לכל הקריאות לפונקציה. קריאה שנייה ל-`dfs` הייתה מתחילה עם הצמתים מהקריאה הראשונה. התחלה עם `None` ויצירת רשימה חדשה בפנים עוקפת את המלכודת הזו.

## הקוד: מחסנית

BFS השתמש בתור: הראשון שנכנס הוא הראשון שיוצא. DFS יכול להשתמש במקום זה ב**מחסנית** (stack): **האחרון שנכנס הוא הראשון שיוצא**, כמו ערימת צלחות. תמיד לוקחים את הצלחת מלמעלה, כלומר את זו ששמתם שם אחרונה. כך DFS ממשיך תמיד לעבוד על הצומת החדש ביותר שמצא, וזה בדיוק מה שגורם לו לרדת לעומק.

רשימה ב-Python היא מחסנית מוכנה: `append` מניח למעלה, `pop()` לוקח מלמעלה.

```python
def dfs_stack(graph, start):
    visited = []
    stack = [start]                 # last in - first out
    while stack:
        node = stack.pop()          # take the node that was added last
        if node in visited:
            continue
        visited.append(node)
        for neighbour in reversed(graph[node]):   # reversed, so the first neighbour is on top
            if neighbour not in visited:
                stack.append(neighbour)
    return visited

print(dfs_stack(graph, 'A'))   # ['A', 'B', 'D', 'E', 'F', 'C', 'G']
```

שימו לב כמה זה דומה לקוד של BFS. מחליפים את המחסנית בתור, ו-DFS הופך ל-BFS. הגרסה הזו גם בטוחה יותר בגרפים גדולים מאוד, כי רקורסיה עמוקה מאוד עלולה להגיע למגבלת הרקורסיה של Python.

## מציאת מסלול עם DFS

DFS יכול גם למצוא דרך מצומת אחד לאחר: יורדים לעומק, ואם שכן מוביל אל היעד, שמים את הצומת הנוכחי בתחילת המסלול הזה.

```python
def find_path(graph, node, goal, visited=None):
    if visited is None:
        visited = set()
    if node == goal:
        return [node]
    visited.add(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            rest = find_path(graph, neighbour, goal, visited)
            if rest is not None:
                return [node] + rest
    return None

print(find_path(graph, 'A', 'C'))   # ['A', 'B', 'E', 'F', 'C']
```

הוא מצא מסלול **כלשהו**, אבל תסתכלו עליו: 4 צעדים, כש-`A` ו-`C` הם שכנים ישירים! DFS נכנס קודם למנהרה של `B` והלך בה כל הדרך מסביב. **DFS מוצא מסלול, לא את המסלול הקצר ביותר.**

## מתי להשתמש ב-DFS

- **טוב:** כדי לענות על "**האם יש דרך כלשהי** מכאן לשם?" או "לאילו מקומות אני יכול להגיע בכלל?".
- **טוב:** כדי לבקר ב**כל** צומת, למשל רובוט שחייב לבדוק כל חדר בבניין, או ספירת האיים הנפרדים במפה.
- **טוב:** חידות שבהן מנסים בחירה וחוזרים אחורה אם היא נכשלת, כמו פתרון מבוך או סודוקו. גם הרבה מחוללי מבוכים משתמשים ב-DFS כדי לחצוב את המסדרונות שלהם.
- **טוב:** הוא משתמש במעט זיכרון, כי הוא זוכר רק את המסלול הנוכחי ולא טבעת שלמה של צמתים.
- **פחות טוב:** המסלול שהוא מוצא יכול להיות ארוך ומשונה. למסלול הקצר ביותר, השתמשו ב-BFS או ב-A\*.
