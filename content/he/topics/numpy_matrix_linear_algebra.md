# אלגברה לינארית

NumPy יודעת לעבוד עם מטריצות, שהן טבלאות מלבניות של מספרים. הן שימושיות במדע, בהנדסה, בגרפיקה ובעוד הרבה תחומים.

## פעולות על מטריצות

השתמשו ב-`@` לכפל מטריצות. זה שונה מ-`*`, שכופל ערכים תואמים איבר-איבר.

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print(A * B)
# [[ 5 12]
#  [21 32]]

print(A @ B)
# [[19 22]
#  [43 50]]
```

השחלוף (transpose) מחליף בין שורות לעמודות:

```python
print(A.T)
# [[1 3]
#  [2 4]]
```

## פתרון מערכת משוואות לינאריות

`np.linalg.solve` יודעת לפתור משוואות שנכתבות כמשוואה מטריציונית, `A @ x = b`.

```python
# x + y = 5
# 2x + y = 7
A = np.array([[1, 1],
              [2, 1]])
b = np.array([5, 7])

x = np.linalg.solve(A, b)
print(x)  # [2. 3.]
```

כלומר הפתרון הוא `x = 2` ו-`y = 3`.
