# בוחן קבצים

בדקו מה אתם יודעים על קריאה וכתיבה של קובצי טקסט. ענו על כל השאלות, ואז לחצו על **הגשת התשובות** כדי לראות את הציון ואת התיקונים.

## אילו מהטענות הבאות על קובצי טקסט ב-Python נכונות?
- [x] הפקודה `with` מבטיחה שהקובץ ייסגר כשנסיים לעבוד איתו.
  > נכון! זו הסיבה העיקרית שבגללה פותחים קבצים עם `with`.
- [ ] Python יכולה לקרוא קובצי טקסט, אבל לא יכולה לכתוב אליהם.
  > Python יכולה גם לקרוא וגם לכתוב קובצי טקסט, והקוד לכל אחד מהם קצר.
- [x] אפשר לקרוא קובץ טקסט שלם לתוך מחרוזת אחת, או להשתמש בלולאה כדי לקרוא אותו שורה אחר שורה.
  > נכון! שתי הדרכים עובדות, אז אפשר לבחור את זו שמתאימה למשימה.
- [ ] קובץ `.txt` יכול לשמור עיצוב כמו טקסט מודגש וגודלי גופן.
  > קובץ `.txt` מכיל רק טקסט פשוט, בלי עיצוב.
- [x] קובץ `.csv` שומר נתוני טבלה, עם פסיקים שמפרידים בין הערכים.
  > נכון! CSV הוא ראשי תיבות של comma-separated values (ערכים מופרדים בפסיקים). כשפותחים אותו ב-Excel, כל ערך נכנס לתא משלו.
> השתמשו ב-`with` כדי לפתוח קבצים בבטחה. קובצי `.txt` מכילים טקסט פשוט, וקובצי `.csv` מכילים נתוני טבלה מופרדים בפסיקים.

## הקובץ `data.txt` מכיל את הטקסט `hello`. מה הוא יכיל אחרי שהקוד ירוץ?
```python
with open('data.txt', 'w') as f:
    f.write('bye')
```
- [ ] `hellobye`
  > זה מה ש-`'a'` (הוספה) היה עושה. `'w'` לא שומר את התוכן הישן.
- [x] `bye`
  > נכון! `'w'` מרוקן את הקובץ ברגע שהוא נפתח, ואז נכתב לתוכו `bye`.
- [ ] `hello`
  > `'w'` פותח את הקובץ לכתיבה, ולכן `f.write('bye')` כן משנה אותו.
- [ ] כלום, כי Python מעלה שגיאה כשהקובץ כבר קיים.
  > `'w'` עובד בלי בעיה עם קובץ קיים. הוא פשוט מוחק את מה שהיה בו.
> `'w'` (כתיבה) **מוחק** את הקובץ ומתחיל אותו מחדש, ריק. שימו לב: התוכן הישן נעלם.

## בקובץ `log.txt` יש שתי שורות, `A` ו-`B`. מה הוא יכיל אחרי שהקוד ירוץ? (התשובות מציגות את השורות בשורה אחת.)
```python
with open('log.txt', 'a') as f:
    f.write('C\n')
```
- [ ] C
  > זה מה ש-`'w'` היה עושה. `'a'` שומר את השורות הישנות.
- [ ] A B
  > `f.write('C\n')` כן מוסיף שורה לקובץ.
- [x] A B C
  > נכון! `'a'` (הוספה) שומר את כל מה שכבר יש בקובץ ומוסיף את הטקסט החדש בסופו.
- [ ] C A B
  > `'a'` תמיד מוסיף טקסט חדש ב**סוף** הקובץ, אף פעם לא בהתחלה.
> `'a'` (הוספה, append) מוסיף לסוף הקובץ ושומר את מה שכבר נמצא בו. זה המצב המתאים לדברים כמו קובצי לוג.

## הקובץ `scores.txt` **עדיין לא קיים**. אילו טענות נכונות?
- [ ] `open('scores.txt', 'r')` יוצר קובץ חדש וריק לקריאה.
  > אין טעם לקרוא קובץ שלא קיים, ולכן Python לא יוצרת אותו.
- [x] `open('scores.txt', 'w')` יוצר קובץ חדש וריק.
  > נכון! `'w'` יוצר את הקובץ אם הוא חסר.
- [ ] `open('scores.txt', 'a')` מעלה שגיאה, כי אין למה להוסיף.
  > `'a'` יוצר את הקובץ אם הוא חסר, בדיוק כמו `'w'`.
- [x] `open('scores.txt', 'r')` מעלה שגיאת `FileNotFoundError`.
  > נכון! `'r'` (קריאה) פותח רק קבצים שכבר קיימים.
> `'r'` נועד לקריאה של קובץ קיים. `'w'` ו-`'a'` נועדו לכתיבה, ושניהם יוצרים את הקובץ אם הוא לא קיים.

## בקובץ `notes.txt` יש שלוש שורות: `one`, `two` ו-`three`. מה יהיה ב-`content` אחרי שהקוד ירוץ?
```python
with open('notes.txt', 'r') as f:
    content = f.read()
```
- [ ] רק השורה הראשונה, `"one"`
  > `f.read()` קורא את כל הקובץ, לא שורה אחת.
- [ ] רשימה של השורות, `["one", "two", "three"]`
  > `f.read()` לא מפצל את הקובץ לרשימה. מקבלים מחרוזת אחת.
- [ ] מספר השורות, 3
  > `f.read()` מחזיר את הטקסט עצמו, לא ספירה.
- [x] כל הקובץ כמחרוזת אחת, `"one\ntwo\nthree\n"`
  > נכון! `f.read()` מחזיר את כל מה שיש בקובץ כמחרוזת אחת, כולל ה-`\n` בסוף כל שורה.
> `f.read()` קורא את **כל** הקובץ לתוך מחרוזת אחת. זה נוח לקבצים קצרים שרוצים לטפל בהם בבת אחת.

## בקובץ `notes.txt` יש שלוש שורות: `one`, `two` ו-`three`. מה הקוד הזה מדפיס?
```python
count = 0
with open('notes.txt', 'r') as f:
    for line in f:
        count += 1
print(count)
```
- [x] 3
  > נכון! לולאת `for` על קובץ נותנת שורה אחת בכל סיבוב, ולכן הלולאה רצה שלוש פעמים.
- [ ] 1
  > הלולאה לא מקבלת את כל הקובץ בבת אחת. היא מקבלת אותו שורה אחר שורה.
- [ ] 14
  > זה מספר התווים בקובץ. הלולאה עוברת על שורות, לא על תווים.
- [ ] 0
  > פתיחת הקובץ עם `'r'` לא מרוקנת אותו, ולכן הלולאה כן רצה.
> לולאת `for` על קובץ פתוח קוראת אותו **שורה אחר שורה**. זו הדרך המתאימה כשרוצים לטפל בכל שורה בנפרד, או כשהקובץ גדול.

## השורה `"5,25\n"` נקראה מקובץ. מה מחזיר `line.strip().split(',')`?
- [ ] `[5, 25]`
  > `split` מחזיר מחרוזות, לא מספרים. משתמשים ב-`int(...)` כדי להפוך כל אחת מהן למספר.
- [ ] `["5,25"]`
  > זה היה קורה בלי ה-`','`. כאן המחרוזת נחתכת בכל פסיק.
- [ ] `["5", "25\n"]`
  > `strip()` רץ קודם ומסיר את ה-`\n` מסוף השורה.
- [x] `["5", "25"]`
  > נכון! `strip()` מסיר את ה-`\n` שבסוף, ו-`split(',')` חותך את המחרוזת בפסיק לרשימה של שתי מחרוזות.
> `strip()` מסיר רווחים ואת תו השורה החדשה משני הקצוות של מחרוזת. `split(',')` חותך מחרוזת לרשימה בכל פסיק.

## הקובץ `data.txt` מוצג למטה. מה הקוד מדפיס?
```python
# data.txt:
# x,y
# 1,1
# 2,4
# 3,9

x_values = []
y_values = []
with open('data.txt', 'r') as f:
    next(f)
    for line in f:
        x, y = line.strip().split(',')
        x_values.append(int(x))
        y_values.append(int(y))
print(x_values, y_values)
```
- [ ] `[1, 1] [2, 4]`
  > בכל **שורה** יש `x` ו-`y`, אבל הקוד שם את ערכי ה-`x` ברשימה אחת ואת ערכי ה-`y` ברשימה אחרת, עמודה אחר עמודה.
- [ ] `['x', 1, 2, 3] ['y', 1, 4, 9]`
  > `next(f)` מדלג על השורה הראשונה, ולכן הכותרת `x,y` לא מגיעה לרשימות.
- [x] `[1, 2, 3] [1, 4, 9]`
  > נכון! הכותרת מדולגת, וכל שורה מוסיפה את הערך הראשון שלה ל-`x_values` ואת השני ל-`y_values`.
- [ ] `['1', '2', '3'] ['1', '4', '9']`
  > `int(x)` ו-`int(y)` הופכים את המחרוזות למספרים לפני שהם נוספים לרשימות.
> כדי לקרוא **עמודות** של נתונים לרשימות נפרדות, מתחילים עם רשימה ריקה לכל עמודה. אחר כך, בכל שורה, מפצלים אותה ומוסיפים כל ערך לרשימה שלו. `next(f)` מדלג על שורת כותרת.
